# Contributing to Boot Bitch

## Reporting a problem

Bug reports are the most useful contribution. Open an issue through the
provided bug-report form and describe the problem in one short paragraph:
(1) the Boot Bitch version you ran, (2) the affected distribution and
release, (3) the behavior you saw, and (4) the tool's session log —
exported from the Logs tab (Save As…) or the log file under the
application's log directory — attached or pasted.

Privacy reminder: the session log may contain device and system identifiers;
review it before posting and remove anything you do not want to share.
