# Boot Bitch documentation

Public documentation for Boot Bitch:

- [Testing Boot Bitch](testing.md) — test tiers, the CI-equivalent checks and
  disposable-VM integration testing.
- [Publishing a Boot Bitch release](publishing.md) — release preparation,
  artifact builds, stabilization and the GitHub publication steps.

are intentionally not part of the published tree; they are kept in the
maintainers' private development notes.
